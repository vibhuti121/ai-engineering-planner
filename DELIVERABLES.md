# Deliverables

Each deliverable asked for in the brief, and the file that answers it.

| # | Deliverable | Where it is |
|---|---|---|
| 1 | **Working application** | `app/` — FastAPI service plus a zero-build vanilla-JS UI. Run `.venv/bin/uvicorn app.main:app --port 8000` and open <http://localhost:8000>. Starts with **no credentials** in `demo` mode, replaying a real captured run. |
| 2 | **Test input and output** | Input `samples/sample-prd.pdf`, generated by the committed `tools/make_sample_prd.py`. Output `samples/sample-output.json` and `samples/sample-output.md` — a real run, 17 tasks over 9 waves. Unit tests: `.venv/bin/pytest -q`. |
| 3 | **README** | `README.md` — quickstart, the design decision that matters, the caching argument, architecture, API surface, limitations. |
| 4 | **AI prompts used** | `AI_PROMPTS.md` — every shipped prompt quoted verbatim (Section A), the development prompt trail and the bugs it uncovered (Section B), and how the product prompt evolved (Section C). Raw files in `app/prompts/`. |
| 5 | **Assumptions made** | `ASSUMPTIONS.md` — numbered assumptions, each written as *assumption → decision → what changes if it is wrong*. |

**Bonus from the brief — a pasteable prompt for a coding agent per task.** Generated for every
task on the `agent_prompt` field, rendered into the markdown export, and copyable from the UI.
See README, *"The bonus: prompts that are actually pasteable"*.

## The 60-second tour

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --port 8000     # open localhost:8000, drop in samples/sample-prd.pdf
.venv/bin/pytest -q                            # the tests
```

No API key needed for any of that.
